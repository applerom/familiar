# Вторая вымышленная семья Familiar

Все люди, свидетельства, справка и выгрузка придуманы автором исходного прохода
12.11.2026. Это не родословная пользователя и не исторический источник.
`inputs/` сохраняет исходный рассказ без исправления фамилий и дат. Имена
придуманы автором прохода; исторические обстоятельства в рассказе требуют
отдельной проверки. Изображения — однотонные заглушки, не имитации документов.

Повторить неделю в двух **новых** каталогах:

```powershell
uv run python -X utf8 scripts/replay_russian_family.py --out tmp/russian-family --report tmp/russian-report
```

Скрипт вызывает публичные команды: русский init, память, обе бумаги, GEDCOM,
семь явных решений и точную отмену, письмо, ожидание, главу, материал для чтения и сборку предпросмотра.
Подтверждение независимого читателя сценарий не имитирует.
Ничего из настоящего пилота он не читает. `family/` — сохранённое конечное
состояние вымышленной семьи, `results/` — три полных текста и компактное
свидетельство прохода. Заглушки заново создаются скриптом и не хранятся в git.

В главе те же слова разделены на `prose` по людям; фрагмент о брате скрывается
только от читателя. `field_subjects` справки относит выбранные два поля к Эмме;
`excerpt` не включает полный лист и брата. Это явная разметка, не чтение по словам.
Назначение людей фрагментам проверяет читатель. Вступление тоже разделено:
место рождения живой дочери не уходит читателю без её разрешения. В текущем маршруте вырезка
текстовая; картинки не прошли отдельное чтение и не публикуются.

## Живой показ

Русский кабинет: <https://applerom.github.io/familiar/ru/>. Английский показ
остаётся в корне сайта. Обе вымышленные семьи собираются одной командой:

```sh
uv run python -X utf8 scripts/build_demo_site.py --out _site
```

Сборка работает на временных копиях и не подтверждает чтение автоматически.
Русское чтение сохранено в `family/.state/attestations.json`; область и правки
описаны рядом в `CONTRACT.md`. Для русского показа используется
`desk export-demo --public-reader`: читательская проекция исключает прозу
о живых и неизвестных, оставляя имена и родство. Исходная выгрузка сохранена;
неподтверждённая смерть из неё убрана с активной временной шкалы Готлиба.

На русском показе есть ссылка English; обратная ссылка «По-русски» находится
в английском «Расследовании». Английская оболочка читателя и его подтверждённые
входы не менялись. Пока это одна глава с текстовой вырезкой и детским вопросом,
без отдельного детского рассказа, снимков документов и истории изменения весов.
