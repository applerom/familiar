# Вымышленная семья Корнеевых-Шмидт · второй проход, 12.11.2026

Вторая вымышленная семья движка Familiar, придуманная для прохода
`familiar-stranger-walk-2.md`. Она не чистая, а такая, какие бывают: русскоязычная, XX век,
поволжские немцы. Все люди, бумаги и выгрузка выдуманы. Сканы — пустые картинки-заглушки;
`*.jpg` в git не входят (`.gitignore`), подойдёт любая картинка с тем же именем.

## Кто есть кто

Хозяйка — Ирина Соколова, 1979 г. р. Бабушка Эмма (1931–2009), урождённая Шмидт, в 1941 году
десятилетней выселена с Волги (Гнаденфлюр) в Павлодарскую область. Прадед Готлиб (по-русски Богдан)
ушёл в трудармию и не вернулся. Прабабушка Мария — Келлер или Кёлер. Брат бабушки Фридрих, "Федя",
1935 г. р., попал в детский дом. О нём молчали; около 1985 года он будто бы "нашёлся, но знаться не
захотел". Дед Андрей Корнеев приехал на целину. Мама Людмила (1957, Павлодар) жива. Тётя Нина
с 1995 года в Германии, бабушкины документы у неё. Выгрузку MyHeritage сделал её сын Александр.

## Что в ней трудного (зачем она движку)

- **Отчество меняется по бумагам**: Богдановна (1957) и Готлибовна (1994) — одно лицо.
  Отчества в модели движка нет.
- **Документы на двух языках**: русско-казахский бланк 1957 года; русская справка 1994 года
  с немецким переводом, где имя брата, возможно, дописано переводчиком.
- **Выгрузка** латиницей и кириллицей, с отчеством внутри имени, с замужней фамилией как главной
  (Maria /Schmidt/ + NOTE "geb. Keller", Nina /Wagner/), со Smart Match (QUAY 0) и однофамильцем
  из книги памяти трудармейцев. Буквального совпадения "имя фамилия" нет ни у одной из семи пар,
  поэтому кандидатов ноль.
- **Чужая догадка спорит с памятью**: в выгрузке Фридрих "умер в детдоме до 1945", а бабушка
  говорила, что он нашёлся.
- **Кто жив, не знает никто**: прадед 1899 года без бумаги о смерти; брат 1935 года, который,
  может быть, жив. Это ломает тексты для хозяйки (см. отчёт).
- **Человек, о котором молчали**, стоит в той же бумаге, что и героиня первой главы.

## Порядок сборки

Из пустого каталога; `F` — установленный `familiar`.

1. `F instance init ./shmidt --language ru`, затем заменить `familiar.toml` на здешний.
2. `F --root shmidt intake memory day1-memory.toml`
3. `F --root shmidt intake paper day1-paper-svidetelstvo.toml --original svidetelstvo-1957.jpg`
4. `F --root shmidt intake gedcom day2-export-myheritage.ged --id export-wagner-2026-11`
5. `day2-identity-decisions.json` → `tree/identity-decisions.json` (семь слияний; `{}` — отмена).
6. Решение агента, для которого у движка нет команды: в `tree/snapshot/people.json`
   у `irina-2026-11-12-gottlieb` поставить `"living": false` (1899 г. р., трудармия).
   Брат `friedrich` остаётся живым.
7. `day3-version-*.json` → `versions/`, `day3-case-*.json` → `cases/`,
   `day3-request-*.json` → `family/questions/` (без префикса `day3-`).
8. День 5: `F --root shmidt intake paper day5-paper-spravka.toml --original spravka-1994.jpg`.
   `day5-answer-nina.json` → `family/answers/nina-spravka-answer.json`. В просьбе `nina-spravka`
   выставить `state = answered` и `answer = nina-spravka-answer`. Заменить версию и дело
   файлами `day5-*`.
9. День 6: `F --root shmidt feed new volga-1941`, положить `day6-feed.json`, `day6-chapters.json`,
   `day6-documents.json`. Вариант `day6-chapters-with-document.json` с вырезкой из справки
   движок блокирует (TRUST-06: в справке назван, возможно, живой брат).
